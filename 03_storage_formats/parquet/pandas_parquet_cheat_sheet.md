Памятка инженера данных: Pandas, PyArrow и Apache Parquet
1. Архитектурный треугольник: кто за что отвечает
Компонент,Где живёт,Роль в системе,Зачем нужен
Pandas,Оперативная память (RAM),Вычисления и аналитика,"Предоставляет табличную структуру DataFrame, функции фильтрации, группировки и математических агрегаций."
Apache Parquet,Постоянная память (Диск / S3),Стандарт бинарного файла,"Хранит табличные данные в сжатом колоночном виде, оптимизированном для чтения аналитических срезов."
PyArrow,Движок / Мост между RAM и диском,Низкоуровневый транслятор,Написан на C++. Выполняет физическую сериализацию/десериализацию данных между форматом памяти Pandas и файлами Parquet.

import pandas as pd работает в памяти. При вызове to_parquet() или read_parquet() Pandas автоматически подключает установленный в системе pyarrow в качестве низкоуровневого движка (engine='pyarrow').

2. Строчные vs Колоночные форматы
СТРОЧНЫЙ (CSV, JSON, Avro):
Строка 1: [ID: 1, User: 101, Status: 'paid', Amount: 1200]
Строка 2: [ID: 2, User: 102, Status: 'fail', Amount: 500]

КОЛОНОЧНЫЙ (Parquet):
Колонка ID:     [1, 2]
Колонка User:   [101, 102]
Колонка Status: ['paid', 'fail']
Колонка Amount: [1200, 500]
Преимущества колоночного формата:
Колоссальное сжатие (Compression): в рамках одной колонки хранятся данные строго одного типа. Алгоритмы сжатия (snappy, gzip, zstd) упаковывают однородные байты в 5–10 раз плотнее текстовых форматов.

Проекция (Projection / Column Pruning): если из 100 колонок таблицы требуются только две, Parquet физически читает с диска только байты этих двух колонок, пропуская остальные 98.

Предикатный пушдаун (Predicate Pushdown): метаданные файла хранят минимальные и максимальные значения блоков. Скрипт может отсечь ненужные диапазоны строк ещё до их загрузки в оперативную память.

4. Базовые структуры Pandas
DataFrame (Датафрейм): двумерная таблица с именованными колонками и строковыми/числовыми индексами.

Series (Серия): одна изолированная колонка датафрейма (одномерный типизированный массив с индексами).
import pandas as pd

# Создание DataFrame вручную из словаря
data = {
    'order_id': [1001, 1002, 1003],
    'status': ['paid', 'cancelled', 'paid'],
    'amount': [1200.0, 500.0, 750.0]
}
df = pd.DataFrame(data)

5. Ввод и вывод данных (I/O)
Запись в Parquet
df.to_parquet(
    'orders.parquet',
    engine='pyarrow',       # движок сериализации
    compression='snappy',   # быстрый кодек сжатия (по умолчанию)
    index=False             # отключает запись служебных номеров строк 0, 1, 2...
)

Чтение из Parquet
# Чтение файла целиком
df = pd.read_parquet('orders.parquet')

# Чтение только конкретных колонок (экономит до 90% RAM)
df_sub = pd.read_parquet('orders.parquet', columns=['status', 'amount'])

# Чтение с фильтрацией на уровне диска (Predicate Pushdown)
df_filtered = pd.read_parquet(
    'orders.parquet',
    filters=[('status', '==', 'paid'), ('amount', '>', 500)]
)

Другие форматы
# CSV
df = pd.read_csv('data.csv', sep=',')
df.to_csv('output.csv', index=False)

# JSON
df = pd.read_json('events.json')
df.to_json('output.json', orient='records', indent=2)

7. Фильтрация данных (Boolean Indexing)
В Pandas условия проверяются поэлементно над всей колонкой:

Вместо логического and используется побитовый оператор &.

Вместо логического or используется побитовый оператор |.

Каждое отдельное условие всегда заключается в круглые скобки (...), так как приоритет & выше, чем у знаков сравнения ==, >, <.

# Одиночное условие
paid_orders = df[df['status'] == 'paid']

# Несколько условий через И (&)
large_paid = df[(df['status'] == 'paid') & (df['amount'] >= 1000)]

# Несколько условий через ИЛИ (|)
target_orders = df[(df['status'] == 'paid') | (df['status'] == 'pending')]

# Проверка вхождения в список (.isin)
cities = df[df['city'].isin(['Moscow', 'Yerevan'])]

8. Группировка и агрегация данных
1. Подсчёт одной метрики
# Сумма по одной колонке для каждого города
city_revenue = df.groupby('city')['amount'].sum()
2. Подсчёт нескольких метрик по одной колонке
# Возвращает DataFrame с колонками 'count' и 'sum'
city_stats = df.groupby('city')['amount'].agg(['count', 'sum'])
3. Именованная агрегация (Named Aggregation)
Стандарт для чистого кода: позволяет задавать понятные имена результирующим колонкам.
summary = df.groupby('city').agg(
    total_orders=('order_id', 'count'),    # Всего строк по группе
    total_revenue=('amount', 'sum'),       # Сумма выручки
    avg_check=('amount', 'mean'),          # Средний чек
    unique_users=('user_id', 'nunique')    # Число уникальных покупателей
).reset_index()                            # Возвращает 'city' из индекса в обычную колонку
